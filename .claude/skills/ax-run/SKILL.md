# AX 그래프 실행

요구사항: $ARGUMENTS

## 준비
- `node .ax/bin/ax.cjs status`로 세팅 완료를 확인합니다. 미완료면 `/ax-setup`을 먼저 제안합니다.
- `node .ax/bin/ax.cjs show graph`로 노드·엣지를 읽고, `graph mermaid` 결과를 사용자에게 한 번 보여줍니다.
- 진행 상황은 작업 목록(TodoWrite 등)에 노드 단위로 표시합니다.

## 노드별 실행
| kind | 실행 방법 |
|---|---|
| `human` | AskUserQuestion으로 승인·선택을 받습니다. 나가는 엣지의 라벨(예: "승인", "수정 요청")을 선택지로 씁니다. **사용자 응답 없이 넘어가지 않습니다.** |
| `agent` | `agent` 필드의 서브에이전트를 Agent 도구로 호출합니다 (`main`이면 직접 수행). 이전 노드의 결과 중 필요한 것만 전달합니다. |
| `loop` | `/ax-loop` 절차를 그대로 따릅니다. 명세 노드의 수용 기준을 함께 전달합니다. |
| `check` | `.ax/project/harness.json`의 검사 명령을 실행합니다. 필수 검사 실패 시 다음 노드로 가지 않고, 직전 `loop` 노드로 돌아갈지 사용자에게 묻습니다. |

## 이동 규칙
- 나가는 엣지가 하나면 그대로 진행합니다. 여러 개면 노드 결과(사람의 선택 등)에 맞는 라벨의 엣지를 고릅니다.
- 순환 엣지(예: 리뷰 → 구현)는 사람이 선택했을 때만 탑니다.
- 그래프에 없는 단계를 임의로 추가하지 않습니다. 그래프가 맞지 않다고 판단되면 진행을 멈추고 `/ax-setup graph`로 수정하자고 제안합니다.

## 마무리
노드별 결과를 5줄 이내로 요약하고, 사용자가 원하면 커밋·PR을 진행합니다.

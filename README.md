# physical-battle

반응속도 대결, 동체시력 대결 등 핸드폰으로 측정할 수 있는 여러 피지컬 테스트 미니게임을 모아 둔 앱

- 서비스 유형: custom
- 플랫폼: 모바일 웹 브라우저 + 앱인토스(토스 미니앱)
- 스택: TypeScript + Three.js + Rapier
- 주요 사용자: 기록·순위로 실력을 겨루는 경쟁 지향 플레이어

## AI 작업 방식
이 프로젝트는 AX AI 엔지니어링 킷으로 세팅되었습니다. 설정 한눈에 보기: `node .ax/bin/ax.cjs render --open` · 킷 설명: [.ax/README.md](.ax/README.md)
